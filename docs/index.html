HearThis

Native Windows desktop audio identification system in modern C++17. Captures system audio playback via WASAPI loopback without microphone bleed.

Windows 10 / 11 Native 350 KB Standalone Executable Zero Third-Party Dependencies WASAPI Loopback Capture
Download for Windows (v1.2.0) View Source on GitHub

WASAPI Loopback Capture

Captures 48 kHz stereo system audio directly from the Windows audio rendering endpoint without microphone noise or ambient room bleed.

Zero-Dependency Architecture

Links strictly against native Windows system DLLs (winhttp, bcrypt, crypt32, user32, dwmapi). Requires no Python runtime or external frameworks.

RMS Silence Energy Gating

Analyzes incoming audio buffers against a -50 dBFS energy floor, automatically dropping silent frames to preserve network bandwidth and battery.

Direct Cloud Recognition

Authenticates directly with ACRCloud using native BCrypt HMAC-SHA1 signatures and AudD using streaming multipart HTTP requests.

Technical Architecture Specifications
